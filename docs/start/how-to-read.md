# How to use this site

*Hand-written.*

## Two kinds of pages
The site has **hand-written** pages and **generated reference** pages, and they are kept apart on purpose.

| Area | Kind | What you find there | How often it changes |
|---|---|---|---|
| Start here | hand-written | what the project is, this page, the glossary | at the end of each milestone |
| Explanations | hand-written | one topic per page: what it is, why it matters, how the original game does it, how the new engine does it, how we know | at the end of each milestone |
| Modding guides | hand-written | what each finding means for a mod, with a worked (hypothetical) example | when a finding changes |
| Reference: engine, file formats | generated from the project's working documents | exact addresses, layouts, evidence tables, open questions | with every finding |
| Project status | generated | roadmap with milestone gates, session log | every session |
| Library | hand-written index + generated lists | sources, tools, test fixtures, live captures, external references | with every capture or new tool |

If an Explanation and a Reference page ever disagree, the Reference page is newer: it is regenerated from the working documents every time the site is built, while Explanations are rewritten by hand at milestone ends.

## Confidence tags
Statements on Reference pages carry tags: **[V]** verified in the program or the running game, **[D]** holds for every relevant game file, **[I]** inferred, **[?]** open, **[x]** an earlier claim found wrong. Explanations only state [V] / [D] facts as facts and say so when something is not proven yet. Details: [How we verify](../explain/verification.md).

## Statuses
Milestones and modules are marked **PASS** (its automated gate passes), **IN PROGRESS** or **PLANNED**.

## What is never on this site
Game files, extracted game data and decompiled code. Addresses refer to the PC Steam build 1.0.15.4 (English).
