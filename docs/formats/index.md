# Reference: file formats

Byte-level specifications of the game's file formats, generated from the project's working documents. Every format listed here is read and re-written identically for every file of that type in the game.

<div class="grid cards" markdown>

-   **[QAR archives](qar.md)**

    master/*.dat archives, entry encoding, path hashes.

-   **[FPK / FPKD packages](fpk.md)**

    Packages inside archives; Lua script decoding.

-   **[FOX2 DataSets](fox2.md)**

    Entities, properties and the string table.

-   **[FRT route sets](frt.md)**

    Patrol routes, nodes and route events.

-   **[NAV2 navmeshes](nav2.md)**

    Walkable surfaces used for path finding.

-   **[FoxData containers](foxdata.md)**

    Node-tree container shared by terrain and collision files.

-   **[HTRE / TRE2 terrain](htre.md)**

    Height maps, terrain patches and height queries.

-   **[GEOM collision](geom.md)**

    Collision geometry files (.geom, .geoms, .gskl).

</div>
